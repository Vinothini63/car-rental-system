# Car Rental Management System

A Car Rental Management System developed using C and SQLite.

## Technologies Used
- C
- SQLite
- Google Colab

## Features
- Customer Registration
- View Available Cars
- Rent Car
- Return Car
- Rental History
- Payment Management
- Revenue Report
- Admin Dashboard

## Database Tables
- Customers
- Cars
- Rentals
- Payments

## Project Type
DBMS Mini Project
