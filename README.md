# Car Rental System

A simple Car Rental System developed using C language and Singly Linked List.

## Technologies Used
- C Programming
- Singly Linked List

## Features
- View Cars
- Search Car by ID
- Rent a Car
- Return a Car
- Check Car Availability

## Data Structure Used
**Singly Linked List** is used to store and manage car details dynamically.

## Project Type
First Year Data Structures Project
